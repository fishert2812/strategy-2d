# Strategy 2D — для тредов

- Правила проекта: docs/pravila_proekta.md. Причины и устройство проверок: docs/spravochnik.md (читай разделы из своего задания).
- Замысел игры: docs/design.md. Пункты первой версии: tasks.md. Слова Романа: docs/game.md.
- Godot: версия в .godot-version (2D, Compatibility, вертикальный экран). Если `godot --version` не совпадает: `bash tools/install_godot.sh`.
- Проверка — одна команда: `bash tools/check.sh`. Запусти её перед PR; итоговую строку (out/check.txt) и sha — в отчёт.
- Шаги проверки — отдельные файлы в tools/checks/ (номер_имя.sh); новый шаг — новый файл, check.sh не трогать.
- Тесты: tests/test_*.gd, методы test_* возвращают "" при успехе или текст ошибки. Ошибка скрипта в тесте — провал.
- Числа игры — в файлах данных, не в коде. Картинки героев, эффектов и значков кодом не рисуем.
- Каждый файл в art/ и audio/ — строка в art/LICENSES.md.
- Один PR — одно видимое изменение, до 300 строк кода.
